# 观影 0.8.2：手机旧页面与播放连接恢复

用户实体手机截图仍显示 0.8.0 的错误提示、旧标题布局，并出现「视频不存在」。上一版本只改为 no-store，无法撤销已经缓存在手机的一小时旧 HTML/JS/CSS，且更新前的视频授权在电脑重启后失效。

- 扫码及桌面连接地址使用 `/mobile/版本号/`；脚本与样式带版本参数，根地址和旧版页面路径重定向到最新入口，避免旧缓存覆盖新版。页面明确显示手机版版本。
- 同一域名、端口与 IndexedDB 名称保持不变；手机原笔记和配对凭据不清除。已有效配对的设备扫描新入口后可直接进入片库。
- 视频地址采用包含授权的 `.mp4` / `.webm` 路径，保留 MIME 和字节范围响应；旧 query 授权路径仍兼容。授权撤销仍有效。
- 视频加载失败自动获取新授权，并尽量恢复已记录的播放时间；再次失败给出明确重连按钮，不无限重试。
- 标准化 Windows 路径的斜杠和大小写，复用同一影片的兼容任务；识别上一版本两种路径产生的旧缓存，避免无谓重复准备。旧客户端无法等待准备时明确提示扫码升级，不提供尚未准备的文件。
- 仅记录本机播放状态、错误码、浏览器类型，帮助诊断实体手机问题；不记录授权令牌、视频路径或笔记内容。

验证：模拟一小时旧 HTML/JS/CSS 缓存，从新版入口加载正确脚本；更新前的手机本机笔记保留；真实整部 VC-1/TrueHD 影片兼容副本 1920×1080、1269.48 秒串流；跳转 60 / 600 / 1200 秒；强制旧视频授权失效后自动恢复且保留时间；原有播放、截图、笔记、导出与持久化回归。

升级后在电脑开启「手机 / iPad 连接」，手机重新扫描新版二维码进入，页面应显示「手机版 0.8.2」。不需要清理浏览器数据或重新导入影片。实体小米浏览器仍需用户复核；本次浏览器验证使用隔离移动尺寸 Chromium。
