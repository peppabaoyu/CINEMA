# 观影 0.8.1：手机兼容播放

修复原 MKV 为 VC-1 视频、TrueHD 音频时手机仅有声音没有画面的问题。

- H.264 / YUV420P 的 MKV 优先将视频流原样封装进 MP4，画面不重新编码；不兼容音频转换为 AAC。
- VC-1、MPEG-4 Part 2 等不兼容视频生成 H.264 / YUV420P 手机播放副本；保持原分辨率和帧率，CRF 16 / veryfast，不缩放。此路径不是逐像素无损，AAC 立体声副本也不是原多声道无损音轨。
- 原影片、电脑播放器、影库记录及笔记均保留；播放副本在独立 mobile-playback-cache 中，既不作为重新导入资源，也不作为云端上传。
- 手机首次播放显示准备进度，完成后才打开已校验的文件；下次复用副本。同一影片和多个设备请求合并，单任务顺序处理，避免重复占用资源。
- MP4 / WebM 可直接播放；解码错误或没有解码画面时尝试兼容副本。失败时提供重试并说明原因。
- 支持 HTTP Range 拖动进度；时间轴保持原片尺度，截图保存实际播放的原分辨率画面。自动读取原片中可提取的文字字幕，不翻译；图形字幕尚不转换为文字。
- 停止连接会终止正在生成的副本，不提供未校验的文件；空间不足时不改动原片。取消配对仍会撤销视频访问授权。
- 修复长哈希文件名导致手机横向溢出；可读取原媒体标题时显示媒体标题，不改写用户影片档案。
- 手机网页脚本、样式改为不缓存，避免浏览器继续使用旧播放逻辑。

验证：数据回归；H.264 视频包哈希一致；同一真实 VC-1/TrueHD 片源可见画面和 AAC 解码；1920×1080 手机帧截图；拖动时间轴、笔记回看、重载持久化；原影片和影库副本 SHA256 不变。测试为隔离移动尺寸 Chromium 窗口，实体小米手机仍需刷新页面后确认。

电脑需要开启观影局域网连接；移动设备保持同一 Wi-Fi。首次遇到不兼容片源需等待准备，本次截图对应影片已提前准备兼容副本。
