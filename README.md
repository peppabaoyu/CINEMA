# CINEMA · 观影 0.6.0

一个私人的 Windows 电影与电视剧日记。默认深色界面，提供本机托管影库、时间轴摘记、截图拼图、批量管理、统一账号及电脑 B 站摘记插件。账号服务默认在本机运行，跨电脑同步需要部署可访问的 HTTPS 服务。

本仓库是观影的源代码仓库。影片、截图、笔记数据库、账号数据和本地构建目录不会提交到 GitHub。Windows 播放器 `vendor/mpv/mpv.exe` 由 Git LFS 管理，克隆前请安装并启用 Git LFS。

## 开始使用

双击桌面「观影」。点击「导入影片」打开拖入框，把视频或整个文件夹拖进来就会开始保存。也可直接拖到片库页面，或点击「选择资源 / 选择文件夹」。默认自动识别电影和剧集，不必先填写表格；需要时展开归类选项。

**现在导入会复制完整视频，不再只记住原文件位置。** 每个文件经过复制和 SHA256 校验后，显示「已保存并校验」。此时可以删除影库以外的原下载文件；请保留「观影影库」里的副本。软件不会代你删除来源文件，不压缩、不转码。

- 默认影库存放在 Windows「视频」文件夹下的「观影影库」。导入框会显示具体位置和剩余空间，可改到容量更大的磁盘。位置变更只影响后续导入，已有视频仍在原影库位置播放。
- 每个文件单独显示进度和结果；中途取消会清理未完成副本，已完成的影片仍保留。空间不足或校验失败的文件不会标为成功。
- 同内容影片不重复入库；同名而内容不同的影片不会互相覆盖。与视频同名的 SRT / ASS / SSA / VTT 字幕会一并保存。
- 电影按文件入库；剧集按季集信息或自然文件名排序，也可以把新集数加入已有剧集。
- 旧版仅引用原文件的资源会标记为「待保存」。点击「保存已有资源」后复制并校验，原有影片、集数、进度和笔记 ID 保持不变。成功前请保留原文件。
- 「视频链接」仍是网络播放入口，并不下载视频副本；片库会标记为「网络链接」。
- 片库支持分类、搜索、排序和想看 / 观看中 / 已看状态，影片档案里可设置封面、评分和观后感。

## 本机保存与跨设备

当前 0.6.0 已实现的是**本机托管影库**，并未接通云端账号或网盘上传。删除原下载文件后，电影仍占用影库存储磁盘的空间。电脑关闭后，本机副本不会自动供其他设备访问。

跨设备目标包含两台 Windows、iPad 和小米手机；需要另外接入云端存储、账号服务和网页 / 移动端。一个「观影」账号可设计为分别授权多个网盘，统一展示片库，但每个网盘的容量、单文件限制和播放权限仍独立。连接能力需逐家验证，不能把登录界面视为完成了同步。

## 观看与摘记

| 操作 | 快捷键 |
|---|---|
| 播放 / 暂停 | 空格；双击画面 |
| 后退 / 前进 5 秒 | ← / → |
| 全屏 / 退出全屏 | F / Esc |
| 沉浸观看 | H |
| 静音 | M |
| 上一帧 / 下一帧 | , / . |
| 标记片段开始 / 结束 | I / O |
| 摘录当前台词 | N |
| 直接保存带字幕截图 | S |
| 直接收藏画面（去除软字幕） | B |

**台词片段**：按 I 记下起点，再按 O 结束，填写感想后保存。播放经过的软字幕会收集对应画面；已导入外挂字幕时，按区间提取画面。也可按 N 摘一句，或在「台词」面板勾选多句字幕。每条摘记最多 20 张图片。

每条笔记保留影片、集数、起止时间、台词、感想、标签、标记颜色和原尺寸截图。点击「回看片段」会跳转到起点并在终点附近暂停；「循环」重复播放这一段。截图和画面收藏可返回对应帧，随后逐帧微调。

外挂字幕支持 SRT、VTT、ASS/SSA，可搜索、点击跳转、勾选摘录。内嵌软字幕可直接摘录当前句；图片字幕或硬字幕无法自动转成文本，可手动填写。B 只能去除软字幕，无法去掉已经压制在视频画面里的字。

音轨、字幕轨和字幕延迟在「字幕 / 音轨」中调整。倍速仅提供 1×、1.25×、1.5×、2×。「偏好与备份」可启用剧集自动连播。

## 两种台词图片

在摘记中点击「导出拼图 / 导出图片」：

1. **完整画面连续拼接**：按顺序纵向排列每一幅原图，对应参考图二。
2. **首幅画面＋字幕条**：第一张保留全图，后面截取底部字幕区域，对应参考图一。可选字幕区域高度，并为中间图片勾选「完整画面」开启新的画面段落。

支持细分隔线与附加手写台词。截图使用原视频像素尺寸，PNG 导出不缩小图片；过长的画布会提示分段导出。画布合成使用 8 位 sRGB；HDR 原视频的色深和动态范围不会完整保留到普通 PNG 拼图中。

单次 S/B 直接存入摘记，需要时再添加感想或导出。图文笔记可整体或按影片导出 ZIP，其中包含 Markdown 和图片。

## 日记与数据

观看十秒后记录一次观影日期。评分、观后感保存在影片档案中，并在「观影日记」展示。

数据目录：`%APPDATA%/guanying-diary`。包含 SQLite 数据库、截图和导入的字幕。大体积视频另存于导入框显示的影库位置。

「备份全部日记」生成 ZIP，包含数据库、原尺寸截图、外挂字幕和网站设置；不包含影库视频副本。迁移电脑时请同时保留影库文件夹；单独的笔记 ZIP 不能恢复视频。恢复前自动保存当前日记的安全备份。重装或更新程序不清理数据目录或影库文件夹。

按用户约定，每次更新验证通过后同步桌面固定目录 `Desktop/观影/win-unpacked`，保持「观影.lnk」不变；成功后清理明确属于本软件的旧程序。保留原视频、观影数据和备份，不触碰「读书」。

## 格式与边界

播放引擎使用 mpv，支持常见视频封装及编码，包括 MP4、MKV、AVI、MOV、WebM、HEVC 等；实际可播放性仍取决于文件内容。原视频按字节完整复制后直接解码，未做转码。播放尺寸随窗口等比例适配；HDR、色彩、音频输出受显示器、系统和硬件支持影响，未在 HDR 屏实测。

网页资源入口并不等于自动下载或网页解析器。付费账号、DRM 视频、网页中的特殊播放器和临时鉴权链接不保证可直接导入。茶杯狐网址可自行修改，网站内容和可用性随外部网站变化。

Windows x64 为已打包版本；本版未提供 macOS 构建。

## 开发与验证

克隆后先运行 `git lfs pull`，再执行 `npm install` 和 `npm start`。`vendor/mpv` 存放 Windows mpv 引擎。`npm test` 运行数据和字幕测试；`node test/desktop.cjs` 与 `node test/experience.cjs` 使用隔离测试数据验证真实桌面功能，需要先运行 `scripts/Create-TestFixtures.ps1` 生成测试视频。`node test/import.cjs` 还会测试真实文件拖入、原文件删除后的播放和重启。

`npm run pack -- --config.electronDist=node_modules/electron/dist --config.npmRebuild=false` 打包。

`scripts/Deploy-Desktop.ps1` 会复制并校验暂存程序、执行打包版测试、备份现有数据、正常关闭旧程序、替换并创建快捷方式；失败保留旧版。部署需要当前用户的桌面写入权限，不修改系统 ACL。
